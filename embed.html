Link parameters

You can also add these to the map address yourself:

ParameterWhat it does
lat, lng, zoomStarting position, e.g. lat=43.5446&lng=-80.2489&zoom=16
typesOnly these rack types: stands, wave, rack, bollard, wall_loops, ground_slots, shed, lockers, building, two-tier, other, unknown (comma-separated)
covered=1Only covered or indoor parking
cluster=0Show every location instead of grouping them
legendopen, closed or 0 (hidden)
basemap=streetStart with OpenStreetMap’s street map instead of the bike map (needs a connection)
routes=1Show signed cycling routes on top
search=0Hide the address search box
embed1 for the compact layout. It switches on automatically inside an iframe; 0 turns it off.
